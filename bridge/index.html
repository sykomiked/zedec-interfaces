The flow

ft_transfer_call(chiglet.unog.near, amount, "ethereum|0xRecipient")

The message is pipe-separated, not JSON. The core parser rejects escaped quotes, so a nested JSON message is silently refunded. That cost a real transaction to discover.

Then: the bridge records {nonce, amount, chain, recipient, sender}, a relayer collects 3 of 5 signatures, and the outpost verifies quorum + nonce + cap + chain tag before minting.
