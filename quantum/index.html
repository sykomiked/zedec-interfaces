Period finding OP_QPERIOD

Exact multiplicative order, Shor post-processing, and cycle detection — the classical half of a quantum attack, implemented in a sealed contract.

The honest framing

The contract never runs a quantum computer. It does the part that a quantum computer would be used for, but exactly: find the period r of a mod N, verify it is minimal, then run Shor's classical post-processing to factor N.

This is a defensive primitive. It proves a modulus is broken — which is what you want to know about a legacy chain before you trust it.

Try it — exact, in your browser

Bounds match the contract: r ≤ 2²⁴. Arithmetic is BigInt, deterministic, no floating point — the same constraints the on-chain implementation works under.
