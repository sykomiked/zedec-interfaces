protocol.unog.nearPROTOCOL — the DAO's one seat

All four hold zero access keys. No upgrade path means the rules cannot be changed by whoever holds the key.

Why four contracts instead of one

Because they fail independently. A bug in the bounty logic should not be able to affect the attestation registry, and neither should be able to reach the core.

Separating them also means each can be reasoned about in isolation — 44 KB is reviewable; 250 KB of combined logic is not.
