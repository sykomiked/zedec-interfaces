Why this layer exists

The sealed core deliberately exposes no convenience surface. It is a virtual machine: correct, minimal, and hostile to casual use.

Putting ergonomics in a separate contract means the core can stay sealed forever while the interface layer evolves — and if the interface is wrong, it can be replaced without touching the thing holding the money.

That separation is the reason unog.near can have zero access keys and still be usable.

Same binary, two accounts

zedei.near and outpost.jollydragonroger.near share a SHA-256 (a9bb7408…). That is deliberate: the desk outpost runs the same interface code, so behaviour cannot drift between them.
