Three properties every outpost shares

  • Pinned to the core — each carries the NEAR core's chain tag and code hash. An outpost that does not match will not accept a ticket.
  • Capped — every outpost has an immutable supply ceiling. A compromised quorum can mint up to the cap and not one token beyond it.
  • Same verdict logic — a ticket is TRUE, FALSE, BOTH or NEITHER, and only TRUE mints. An outpost that cannot decide mints nothing.

The original Ethereum contract 0x9f326c206BAcB6f6452e51c7F4aB87b71830CE70 lacked decimal scaling between NEAR's 24 decimals and the EVM's 18. It was deprecated and replaced by 0xAd5580…, which applies SCALE = 1e6.
